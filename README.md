# Online Store Annual Report - Interactive Excel Dashboard

An interactive, data-driven Excel dashboard designed to analyze and visualize the annual sales, order trends, and demographic profiles for an e-commerce platform. This project transforms raw e-commerce transaction data into actionable business insights using dynamic filtering, advanced charting, and KPI tracking.

## 📊 Dashboard Overview

The dashboard provides a holistic view of the store's performance across channels, geography, and demographics. It features interactive **Slicers** at the top and left side, allowing users to filter the entire report seamlessly by **Month**, **Sales Channel**, **Gender**, and **Age Group**.

### Key Visualizations & Features

* **Top 5 Sales According to State:** A horizontal bar chart identifying the highest-performing regions (with Maharashtra, Karnataka, and Uttar Pradesh leading the sales volume).
* **Order Percentage According to Age Group:** A clustered column chart breaking down purchase behaviors by demographic segments (*Adult, Senior Citizen, Youth*) segmented by gender.
* **Compare Sales and Orders:** A combination chart (Line & Clustered Columns) showcasing monthly trends, mapping total revenue against order volumes over the 12-month fiscal period.
* **Overall Percentage of Delivery by Order Status:** A pie chart paired with a breakout column chart tracking fulfillment health metrics (*Delivered (92%), Cancelled, Refunded, Returned*).
* **Sales Percentage According to Gender:** A clean pie chart summarizing market share between Men (35.96%) and Women (64.04%).
* **Order Sales by Channels:** A donut chart highlighting platform distribution across major e-commerce players like Amazon, Myntra, Flipkart, Ajio, and Meesho.

## 🛠️ Tech Stack & Skills Demonstrated

* **Data Visualization:** Custom charting (Donut, Pie, Combo Line/Bar, Clustered Columns).
* **Interactive Design:** Formatted Excel Slicers for dynamic user-driven filtering.
* **Data Analysis:** Pivot Tables and Pivot Charts for multi-dimensional data aggregation.
* **MS Excel:** Use Microsoft Excel to create a detailed analysis.
